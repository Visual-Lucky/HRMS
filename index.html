Project Overview

This Human Resource Management System is a robust C++ console application designed to streamline HR processes including employee management, attendance tracking, payroll, and performance evaluations. The project showcases effective use of C++ programming principles like OOP, file handling, and modular design.

  • Language: C++
  • Type: Console Application
  • Target Users: HR Departments
  • Design: Modular & Extensible
  • Development Tools: Visual Studio / GCC

Key Features

  • Employee CRUD Operations
  • Attendance Tracking & Reports
  • Automated Payroll Calculations
  • Performance Reviews & Feedback

Generate Monthly Salaries for All Employees

void generateAllMonthlySalaries() {
    Employee emp;
    fstream fin("EMPLOYEE.dat", ios::in | ios::out | ios::binary);

    while (fin.read((char*)&emp, sizeof(emp))) {
        emp.autoGenerateMonthlySalary();

        int pos = fin.tellg() - (int)sizeof(emp);
        fin.seekp(pos);
        fin.write((char*)&emp, sizeof(emp));
    }

    fin.close();
}
Mark Attendance

void markAttendance(const char* id) {
    fstream f("EMPLOYEE.dat", ios::in | ios::out | ios::binary);
    Employee e;

    while (f.read((char*)&e, sizeof(e))) {
        if (strcmp(e.empID, id) == 0) {
            e.daysPresent++;

            int pos = f.tellg() - (int)sizeof(e);
            f.seekp(pos);
            f.write((char*)&e, sizeof(e));
            break;
        }
    }

    f.close();
}
